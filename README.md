# 🚀 SkillPath AI – AI-Powered Career Roadmap Generator

### Your Personal AI Career Guide | From Skills to Success

SkillPath AI is an AI-powered career guidance platform designed to help students and beginners identify their skill gaps, explore career opportunities, and build personalized learning roadmaps.

The platform analyzes a user's skills and resume to provide intelligent career recommendations and structured learning paths, helping students move closer to their dream careers.

---

## 🌟 Key Features

- 📄 **Resume Analysis:** Upload your resume and analyze your existing skills.
- 🧠 **AI Skill Gap Analysis:** Identify missing skills required for your target career.
- 🎯 **Personalized Roadmaps:** Generate customized learning paths based on your current skills and career goals.
- 💼 **Career Recommendations:** Discover suitable career opportunities based on your profile.
- 📚 **Learning Guidance:** Get structured guidance to improve technical and professional skills.
- 📊 **Interactive Dashboard:** Track your learning journey and career preparation.
- 👩‍💻 **Student-Friendly Interface:** Simple and accessible experience for beginners.

## ⚙️ Getting Started

Follow these steps to run SkillPath AI locally.

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the Project

```bash
cd skillpath-ai
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the root directory.



```env

```

Keep your API key private. Never upload your `.env` file to GitHub.

### 5. Start the Development Server

```bash
npm run dev
```

The application will start in development mode.

## 🎯 Project Objective

The main objective of SkillPath AI is to bridge the gap between students' current skills and industry requirements.

Many students struggle with questions like:

- Which skills should I learn?
- What career is suitable for me?
- What skills am I missing?
- Which courses should I complete?
- How can I prepare for internships and placements?

SkillPath AI aims to answer these questions through AI-powered career guidance and personalized learning roadmaps.
